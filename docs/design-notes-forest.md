# Forest 阅读记录与时光花园的设计取舍

记录日期：2026-10-25，更新至 0.11.0。本文区分旧文章的观察、本插件已实现的功能与后续建议。

## 阅读范围

已阅读用户保存的《[产品分析：Forest 专注森林](https://www.woshipm.com/evaluating/1053804.html)》正文，作者 lrccy，发表于 2018-06-11，体验版本为 4.1.2、iOS 11.1.2。另查看其“我的森林”配图：同一页面把森林、每日柱形图、总时长和日期放在一起。原网页、配图及个人文件不随本插件分发。

文章提供的设计线索是：入口简短、时间转化为植物、回顾时兼有画面与数字、逐步获得新内容。文中人口属性和市场表现的解释属于作者当时的分析，不足以证明性别、地域或年龄与自制力的因果关系，也不能直接当作本插件用户画像。旧价格、排名及付费方案不用于本项目判断。

[Forest 官方首页](https://www.forestapp.cc/)目前仍以计时、生长和完成后的森林作为核心表达；这次对照以用户保存的旧文章为主，不声称完整评测了最新版 Forest。

## 我们自己的产品基础

时光花园已经有八种植物、分类/程序/网站规则、可跨天的累计生长、可选中断扣减、周相册和单花详情。0.10.0 引入从早到晚的周时间线并增加四角远景层次。0.11.0 将其收紧为限高周索引与固定回顾面板，加入保存种植方案、完成目标时长回顾、任务记忆、永久收藏成就和四种可选主题。

目前核心记录的边界很明确：

- 同时只养一盆，只认可运行中实际观察到的匹配前台时间；离开电脑、重启、休眠间隔不补算。
- 成熟花保存 id、名称、品种、种下/开花时间、目标时长及完成进度；0.11.0 新增自愿填写的短任务备注。仍不保存当时规则快照或逐日累计流水，不为旧花补造任务。
- Hindsight 分类是匹配依据，不能推断“这个人真正专注、学习或有成效”。
- 七项 API 权限不包括任意文件读写、程序启动、应用拦截或桌面悬浮能力。插件页面与后台通过 SQLite 协作，不能依赖页面变量跨运行环境共享。

因此，最适合的方向是：**把已经选择的电脑活动变成可回顾的花园，同时减少每次重新设置的操作。**

## 设计方向与当前状态

| 状态 | 方向 | 在本插件中的实现或建议 | 数据与体验边界 |
|---|---|---|---|
| 0.11.0 已实现 | 周回顾 | 选中周显示开花数、品种数、完成目标时长和品种分布；不受当前花园分页影响，当前盆栽不混入总数 | 标为“完成目标时长”：跨周生长的花全部归到开花周，惩罚前累计时间无法从成熟记录复原，不能称为实际周专注时间 |
| 0.11.0 已实现 | 保存种植方案 | 最多 20 个具名方案，保存花种、规则、目标与惩罚设置，可更新、删除或沿用上次设置，仍由用户确认播种 | 以分类 ID 匹配；分类缺失或不可读取时先说明，播种前检查。预览与载入后均能看到惩罚设置，不复制旧花名称和任务备注 |
| 后续建议 | 真正的每日生长图 | 按本地日期新增每日汇总，扣减单列，显示累计、扣减与净进度，再制作七日小柱图 | 需要与 SQLite/CAS 原子提交，验证跨午夜、夏令时、重试与配额。旧数据没有逐日记录，不能补造历史；本版没有实现 |
| 0.11.0 已实现 | 轻量收藏里程碑 | 首次开花、累计 10 株、收齐八种、累计 100 株获得永久徽章；前三项分别解锁雨后、晚灯、樱枝主题 | 升级时以现存收藏建立核验起点，此后开花累加，删除不减且不撤回徽章。旧版已删的花无法恢复；旧收藏获得日显示核验时刻，不伪造历史日期 |
| 0.11.0 已实现 | 给花留下任务记忆 | 种下时可写最多 280 字符，当前盆栽和成熟花详情均可编辑，不加入系统通知 | 只实现自愿备注，没有自动任务识别、历史分类快照或任务成果核验；旧花保持空白。允许活动的规则不能证明具体任务完成，也不能据此拆分分类时长 |
| 0.11.0 已实现 | 可选的花园主题 | 默认草木晴日，可解锁雨后小憩、晚灯花园、樱枝来信；新贴图与既有可爱绘画风格衔接，用户手动选择 | 只改变背景与装饰，保留投影和落点，不改变生长和惩罚，不根据真实时间强制切换；展示偏好存在本机 |
| 后续建议 | 本地分享卡 | 将选定一周的花园和概况画成一张图，先预览并选择是否包含备注 | 尚未实现。需要先验证宿主沙箱允许的导出方式；不能预先承诺任意写盘或自动上传，不默认暴露个人备注 |

方案、回顾和任务记忆让“种完以后回来看看”和“下一次开始”连接起来；成就与主题给收藏提供轻量反馈。它们不引入金币商店、排行榜或签到惩罚。真正的每日图仍需要另行设计持久化与验证，不能把完成目标时长换个名称就当作每日实际活动。

## 现在不照搬的部分

- **强制离开即死亡、默认枯花、连续签到清零**：桌面工作经常需要切换文档、浏览器、通讯工具。继续默认暂停不惩罚，让严格模式保持自愿；也不以外观变化偷偷引入惩罚。
- **直接复制金币商店与稀有度经济**：目前植物只有八种，先让基础收藏与装饰里程碑有意义，不增加刷时长、买解锁或重复确认的负担。
- **好友竞争、多人连坐**：需要账户、服务端、同步、身份和隐私设计；不是现有离线插件的小改动。
- **真实植树与公益兑换**：需要实际合作与资金履约，不能把虚拟装饰描述为现实公益结果。
- **3D 旋转或自由摆放作为下一步**：目前等距素材是二维绘画，旋转会露出透视问题。先做好对齐、选中、回顾和轻量主题，再考虑可持久化的位置编辑。

## 实现与建议的界线

0.10.0 实现时间线和四角美化；0.11.0 实现紧凑周索引及切换过渡、种植方案、完成目标时长回顾、任务备注、永久收藏成就与主题。逐日时间流水、自动分类归因、分享和社交尚未实现。七项 API 权限、64 MB 额度和 schema 2 不变；旧版不能保留新字段，数据库保护会阻止这类状态更新并让旧版报错，不应降级或混跑新旧版本。退回旧版需恢复升级前备份。具体行为见[0.11.0 功能说明](features-0110.md)。本版验证仍在进行，最终 ZIP 尚未在原生 Hindsight 中安装验证。
