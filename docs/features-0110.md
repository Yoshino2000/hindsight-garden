# 0.11.0：方案、回顾与收藏

本版在已有八种花、累计生长和周相册上，补全下一次播种与回看收藏的入口。基础功能可用，仍为持续迭代的实验性插件；115 项自动测试通过，Chrome 验证使用隔离合成数据，最终 ZIP 尚未在原生 Hindsight 中安装验证。

## 周相册

宽窗口左侧为周索引，右侧固定显示所选周的回顾和花园小图；窄窗口上下排列。每组最多 12 周，按日期从早到晚排列。周列表内部滚动，宽窗口限高 260 px，窄窗口 168 px，不再随周数不断拉长页面。可换组、回到本周，也可通过「日期直达」进入指定日期所在的本地周，包括没有花的周。

选择不同周时，回顾和场景有 220 ms 的轻柔过渡。系统启用减少动态效果时跳过过渡；后台轮询不会重复播放切周效果。每座花园仍最多 25 株，缩略图每组最多 12 座，花多时继续分园。

## 保存种植方案

选择花种、目标分钟数、生长规则和惩罚设置后，填写方案名称并保存。最多 20 个方案，名称为 1～40 字符。可载入、用当前设置更新或删除；删除方案不会删除已经种下的花。

「沿用上次种植设置」保存最近一次实际播种使用的同类设置。方案和上次设置都不复制花名或任务记忆，也不会自动播种。载入后检查规则和惩罚，再填写本次花名并确认。

分类规则仍使用 Hindsight 分类 ID。分类重命名不改变匹配；分类删除、目录读取失败或设置变动时，界面会提示，播种前检查当前分类。方案没有复制一份应用归类表。

## 周回顾的口径

回顾显示：

- 已开花株数。
- 收集品种数与各品种株数。
- **完成目标时长**：所选周开花花朵的目标时长合计。

周以本地周一 00:00 到下周一 00:00 之前为界，按开花日期归属；跨周生长的花把完整目标归到开花周。当前未开花盆栽不计入，翻到另一座花园也不会改变整周总数。「全部」模式显示当前全部收藏的同类统计。

这些数字不能还原当周实际活动时长、每天使用分布或惩罚前累计时间，也不证明任务已经完成。旧数据缺少逐日记录，不能补出七日活动图。删除花后，当前收藏的回顾会随之变化。

## 任务记忆

种下时可自愿写最多 280 字符，例如「读完这一章，整理两个问题」。之后可在当前盆栽的「编辑备注」或成熟花右侧详情中修改、清空。备注随花开保留在本地数据库，不放进开花通知，也不自动复制到下一次播种。

旧花没有备注时保持空白，可由用户自行补写。插件不会猜测旧任务、自动读取历史活动、生成分类快照或将备注当作成果核验。内部字段为 `taskNote`，与旧记录可能已有的其他 `note` 元数据分开。

## 收藏成就

| 成就 | 条件 | 主题奖励 |
|---|---|---|
| 第一朵花 | 累计 1 株 | 雨后小憩 |
| 小小花匠 | 累计 10 株 | 晚灯花园 |
| 八色收藏 | 八种植物均开花 | 樱枝来信 |
| 百花成园 | 累计 100 株 | 收藏徽章 |

成就进度与已获得事实单独持久保存。升级时以当时现存收藏建立核验起点，此后每次开花增加累计数量与品种，删除花不扣回进度，也不撤回已经获得的徽章。旧版已删除的花无法纳入起点；旧收藏在升级时获得的成就显示本次核验日期，不声称知道历史达成日。

## 四种主题

默认「草木晴日」保留原来的绿意。解锁后可手动选择「雨后小憩」的陶蛙和带水珠的蕨叶、「晚灯花园」的暖灯，或「樱枝来信」的浅粉花枝。主题只改变背景与装饰，花位、投影、生长速度和惩罚规则不变；不按真实时间自动切换。

新素材 `assets/collection/milestones.png`、`assets/collection/themes.png` 由内置图片生成工具原创绘制，均为 2172 × 724、带真实透明通道的 PNG 图集，风格参照现有可爱植物素材。现有八种植物、花园小图和环境素材不替换。主题选择使用本地存储，成就与花朵记录使用插件数据库。

## 升级与数据

仍使用 schema 2、七项 API 权限和 64 MB 数据库额度；没有新增网络、历史统计、文件或程序启动权限，也没有新增逐日时间流水、分享或社交功能。

升级前请关闭 Hindsight 后备份，或使用 SQLite 在线备份取得一致副本。新版保留原有花朵和进度，并首次核验收藏成就。

**不要直接降级，也不要同时运行新旧版本。** 0.5.0～0.10.0 虽然能读取 schema 2，却不能保留新增的种植方案、成就和任务备注字段。新版持久保存在数据库中的兼容性保护，会拒绝旧版丢失新字段的状态更新，避免这类写入覆盖新数据；旧页面或后台会因此报错，应关闭并重新打开最新版。更早版本连 schema 2 也不支持。确需退回旧版，应恢复升级前的一致备份，而非仅安装旧 ZIP。

验证结果以[验证记录](verification.md)为准；旧版检查不代替本版最终 ZIP 的原生安装验证。
