# 0.12.0：更紧凑的盆栽与完整主题

本版调整盆栽和播种布局，扩充永久收藏成就，并让四种主题拥有完整配色与摆设。基础功能可用，仍为开发迭代中的实验性预发布版；125 项自动测试通过，已记录 22 项隔离数据的 Chrome 检查；最终 ZIP 尚未在原生 Hindsight 中安装验证。

## 当前盆栽与播种

正常模式在 540 CSS 像素及以上使用两列：

- **当前盆栽**：左侧植物、进度和暂停按钮；右侧约定、规则、任务记忆和开花通知。植物图收至 200 px，并减少上方和周围留白。
- **播种**：左侧种植方案与八种花，右侧名称、任务备注、目标时长、规则、惩罚和通知。规则行与表单间距缩小。

窄窗上下排列，花种使用四列小图。原有独立紧凑盆栽模式保持不变，高清图鉴仍可按需展开。

切换页签会清掉此前成功提示和页面操作错误，仍在发生的后台运行错误继续显示。

## 方案名称更容易分辨

方案选择项显示「自定义内容 · 当前分类或规则 · 目标分钟」，例如「读完一章 · 阅读 · 30 分钟」。分类重命名后，读取到新分类目录时显示随之更新；原自定义名称和分类 ID 不改写。目录不可读取时保留原显示快照并提示，不能把旧名称当作新的匹配依据。

方案仍最多 20 个，只保存花种、目标、规则和惩罚，不复制花名或任务备注。在方案名称中按 Enter 只保存方案，不会种下新花。载入方案后，仍需用户检查并确认播种。

## 20 项永久成就

| 类别 | 条件 | 数量 |
|---|---|---|
| 累计开花 | 1、5、10、25、50、100、250、500、1000 株 | 9 |
| 品种收藏 | 2、4、8 种植物曾经开花 | 3 |
| 品种初绽 | 八种植物各自首次开花 | 8 |

成就列表使用 32 px 小图，窄窗 28 px，支持筛选。点击后从右侧打开非模态详情，展示条件、说明、当前进度、获得日期和主题奖励。不会把详情直接堆在花园下方。

成就仍使用永久累计数量和曾经开花的品种集合；删花不减进度、不撤回已获得成就。主题解锁条件保持原样：第一朵花解锁「雨后小憩」，10 株解锁「晚灯花园」，八种植物解锁「樱枝来信」。新增的其他成就提供收藏反馈，不增加金币或签到惩罚。

从 0.11.0 升级时，`achievementRevision: 2` 使用已有永久计数，一次 CAS 更新补授已满足的新项目，不扫描全部成熟花。原四项获得日期保留；新补授项显示本次核验日期，不猜历史达成日。更早版本仍先从现存收藏建立一次核验起点，无法恢复旧版已经删除的花。

## 四种主题的摆设与配色

| 主题 | 主要摆设 |
|---|---|
| 草木晴日 | 原有秋千、木牌、浇水壶 |
| 雨后小憩 | 叶伞长椅、苔石鸟浴、陶蛙 |
| 晚灯花园 | 灯笼拱椅、木鸟屋、南瓜装饰 |
| 樱枝来信 | 鸟居、神社石灯笼、竹筒手水钵 |

新摆设由内置图片生成功能原创绘制，与现有可爱植物的笔触和颜色相近。三张透明三格图集为 `assets/collection/props-rain.png`、`props-dusk.png`、`props-blossom.png`。默认主题保留原有摆设，新主题替换对应三处摆设，使用简单固定阴影，不增加逐帧阴影计算。

主题配色同时覆盖草坪、岛侧面、花圃和网格、水池、围栏、路径、远景叶片及页面和卡片。花朵使用原插画，不加颜色滤镜。相册缩略图使用同样的摆设和颜色并保持静态；全景仍遵循轻柔动效与系统减少动态效果设置。

几何投影、花位、访客间隔、生长计时和惩罚规则均不改变。主题只影响画面，选择仍保存在本地展示偏好中。
