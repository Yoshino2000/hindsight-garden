# 0.16.0：梦色收藏与中英日界面

本版为八种植物增加隐藏配色，补充永久隐藏收藏成就，加入自动中英日界面，并调整细雨和晚灯效果。仍为开发迭代中的实验性预发布版：基础功能已可用，未经严格全面验证，可能存在问题和风险。

## 八种花，两种配色

| 花种 | 隐藏配色 |
|---|---|
| 向日葵 | 晨粉向日葵 |
| 绣球 | 杏霞绣球 |
| 郁金香 | 晴蓝郁金香 |
| 雏菊 | 浅紫雏菊 |
| 玫瑰 | 月蓝玫瑰 |
| 薰衣草 | 薄荷薰衣草 |
| 波斯菊 | 蜜橙波斯菊 |
| 百合 | 淡樱百合 |

每次开花独立有 **5%** 概率遇到隐藏配色。品种、目标时长和此前结果都不增加概率，没有保底。隐藏花在花园、相册和右侧详情中保留自己的配色。

实际抽签发生在种下新盆栽时；没有随机签的旧活动盆栽在升级时取得一次。随机签先持久保存，开花时才揭晓结果。刷新、重启或 CAS 写入重试不重新抽签。旧成熟花没有隐藏结果时保持普通配色，不回抽，也不按旧记录补造隐藏发现。

## 52 级，26 张卡片

保留原有 36 项条件和已经获得的日期，新增 16 项永久隐藏成就：

| 类别 | 条件 | 数量 |
|---|---|---|
| 隐藏开花数量 | 首次、5、10、25、50 株隐藏花 | 5 |
| 隐藏品种收藏 | 2、4、8 种隐藏配色 | 3 |
| 隐藏初绽 | 八种植物各自的隐藏配色首次开花 | 8 |

合并后为 52 个独立条件、26 张展示卡。详情抽屉保留各级条件、进度与日期；白、蓝、紫、金、彩只表示展示档位，不更改实际条件。

`hiddenCollection` 单独保存永久累计数量与曾经遇见的品种，删除花不扣回，也不撤回已获成就。因此永久进度可能高于当前相册中仍保留的数量。旧版已经删除的花不能还原；隐藏收藏不会从旧普通花推算。

## 自动使用简中、英语或日语

| 打开时的环境语言 | 选择结果 |
|---|---|
| `zh*`，含 `zh-TW` 等地区设置 | 简体中文 |
| `ja*` | 日语 |
| `en*` 及其他语言，例如法语 | 英语 |

界面、动态提示、植物图鉴、成就说明与内置通知模板均使用离线文本。你原来的花名、任务备注、方案名和 Hindsight 分类名保留原文，不随界面语言翻译或改写。改变环境语言后重新打开插件。

## 持续细雨与更清楚的晚灯

雨后小憩使用六条固定错相路径，持续出现少量细雨。从上方落到安全草坪后，才在原地泛起小溅水并消退；叶尖滴水与叶伞微动保留。

晚灯花园的背景、草坪和侧面略暗，原贴图中的三盏灯增加局部暖光，配合草地映照和低频萤火。不会给整株花施加暗色滤镜，也不在花圃上铺一层大光幕。

![持续少量降雨的雨后小憩](screenshots/rain.jpg)

![背景稍暗、三处暖灯的晚灯花园](screenshots/dusk.jpg)

四主题原有水波、反光和荷叶微漂保留。所有特效仍是低负载 CSS 与固定装饰节点，没有新增逐帧 JavaScript 或计时器。关闭动效、隐藏页面、离开花园页签和系统减少动态设置继续生效；缩略图保持静态。

隐藏配色由代码对原花图的花瓣色区选择性换色，沿用线条、叶片与透明边缘，不是新生成的 AI 图片。原有 29 张植物与场景 PNG 不变。图标另更新为 256 × 256、5,448 字节的绿色线条透明 PNG。

## 升级与验证范围

仍为 schema 2、七项 API 权限、64 MB 数据库额度，没有新增网络、文件、历史读取或程序启动能力。成就目录升级到 **revision 4**；已有花朵、进度、有效生长统计及原 36 项的获得日期保留，旧活动盆栽的随机签只建立一次。

更新前关闭旧页面和后台，并在 Hindsight 停止时备份，或使用 SQLite 在线备份取得一致副本。0.15.0 及更早版本不支持新状态，读取可能失败；持久数据库保护会拒绝丢弃新字段或改写同一盆栽随机签的写入。不要混跑或直接降级，确需回退应恢复升级前的一致备份。

本版 **194 项自动测试通过**。连接的 Chrome 已检查英文、日文、法语回退英语、窄窗无横向溢出及自然运行的雨与灯光，使用隔离模拟宿主和演示数据，未读写个人 Hindsight 数据库。

最终 ZIP 尚未在原生 Hindsight 安装验证，操作系统开花通知也未验证。Chrome 的页面语言模拟不会改变 Worker 语言，本轮后台仍按本机中文运行；英文、日文及回退通知模板是在独立 VM 中验证，不能据此宣称浏览器或操作系统已经成功弹出英文通知。完整证据与限制见[验证记录](verification.md)。
