# 0.18.0：更轻的安装包与更简洁的文案

基础功能已经可用，仍在开发迭代。[安装说明](usage.zh-CN.md) · [English guide](usage.en.md) · [验证记录](verification.md)

## 安装包从 29.3 MB 降到 12.1 MB

运行时贴图按各自最大显示尺寸的 3 倍重新生成：盆栽 200 px、花朵详情 135 px、花园摆设按 790 px 宽的场景、主题图 87 px、成就徽章 78 × 104 px、小鸟 28 px、蝴蝶 32 px。高分屏下细节完整，同屏并排对比的逐像素平均差为 0.6–1.5 / 255。全部贴图解码后的内存占用从约 183 MB 降到约 63 MB。

原图保存在仓库的 `assets-source/`，不进入安装包；`scripts/resize-assets.py` 可随时重新生成。秋千保留原图。

## 后台空闲时少写数据库

没种花、暂停、离开电脑或正在使用其他活动时，后台每 6 秒保存一次状态，原来每 2 秒一次。生长、中断扣减、休眠后的间隔处理和时钟回拨仍在当次计时立即保存，生长与扣减的结果和以前一致。

活动切换恰好排在一次计时之后时，这次切换会被完整记下，植物继续生长。
