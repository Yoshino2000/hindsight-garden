# 0.20.0：时长快选与开花揭晓

基础功能已经可用，仍在开发迭代。[安装说明](usage.zh-CN.md) · [English guide](usage.en.md) · [验证记录](verification.md)

## 时长快选

「累计多少分钟开花」旁边多了 30 / 60 / 90 / 120 / 180 五个按钮，点一下就填好目标时长；和当前数值相同的按钮会高亮。仍可以直接输入 1–1440 之间的任意分钟数。载入方案、重置选择后，高亮跟着更新。

## 开花那一刻

插件页面开着时，花一开就会弹出一张开花卡片：这朵花的完整图、名字、品种和累计目标时长。卡片里的花从花盆高度轻轻升起，花瓣向四周飘散，然后停在静止画面；遇见隐藏配色时，卡片会换成淡紫光晕，加上闪光和「遇见隐藏配色」标记。

- 「去花园看看」直接打开这朵花所在的开花周和花园页，并展开它的详情；紧凑模式下会先切回完整花园。
- 「好的」、点卡片外部或按 Esc 关闭。
- 页面关着时开花的，下次打开插件也会补一次揭晓。每朵花只揭晓一次；第一次打开新版本时不会把旧花再弹一遍。
- 动画只播放一次。关闭「轻柔动效」或系统要求减少动态效果时，卡片直接以静止画面出现。
- 系统开花通知照常发送，卡片只在插件页面里出现。

## 数据

沿用 schema 2、成就 revision 4、七项权限、64 MB 和全部贴图。「已揭晓到哪一朵」只记在本机浏览器存储里，和花园收藏数据分开；清掉也只会少弹一次卡片。
