# 0.21.0：开花后自动续种与更清楚的进度

基础功能已经可用，仍在开发迭代。[安装说明](usage.zh-CN.md) · [English guide](usage.en.md) · [验证记录](verification.md)

## 开花后自动续种

播种时勾选「开花后自动续种」，花开的同一刻会用同样的品种、规则、目标时长和中断设置接着种下一盆：花名沿用，任务记忆留空，隐藏配色重新独立抽取。开花那一刻多出来的几秒也记到新的一盆上，活动不中断就不会漏掉时间。

正在生长的盆栽也能随时打开或关闭这个选项，位置在「这盆花的约定」下方、开花通知旁边。开花卡片会提示「下一盆已经种下」。自动续种只影响当前这一盆和它之后的续种，不写进种植方案。

## 进度

- 进度条下方显示还需多久开花，以及多久后进入下一阶段，例如「还需 45 分钟开花 · 15 分钟后长叶」。剩余时间按整分钟向上取，最后一分钟按秒显示。
- 进度不到 1% 时显示「<1%」，不再停在 0%。
- 播种后的「种好了…」提示在开始生长后自动消失。

## 生长状态

「为什么正在生长」在正常生长时收成一行，点开可看当前程序、网站和分类；暂停或不匹配时自动展开，方便排查。手动展开或收起后，在生长状态变化前保持你的选择。

## 数据

沿用 schema 2、成就 revision 4、七项权限和 64 MB。自动续种是当前盆栽上的一个可选标记，关闭时不写入；旧版本读取时会忽略它。不要同时运行新旧版本。
