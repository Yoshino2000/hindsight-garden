# 时光花园：详细使用说明

[中文首页](../README.md) · [English](../README.en.md)

使用电脑时，慢慢养出自己的花园。这是 [Hindsight](https://github.com/Tomotsugu-dev/Hindsight) 的第三方插件，包含可爱风格的 AI 原创植物素材，无需账号或联网。

## 能做什么

- 向日葵、绣球、郁金香、雏菊、玫瑰、薰衣草、波斯菊、百合八种植物，各有种子、发芽、长叶、花苞、开花五个阶段。
- 完整的等距花园场景，花圃面积扩大 23.5%，外围摆设缩到原来的 80%，全岛、花圃和落点仍统一 4/7 投影、左右对称。四角远景加入树冠层次、远山针叶树、种子篮、蕨叶与野草石径，放在岛后，相册缩略图不显示远景。水壶只留贴底阴影，秋千座板的小阴影按插画方向校准，静止时也保持贴合。每座花园最多 25 株，更多收藏放在后续花园，不再固定限制为 200 株。
- 当前花园全景放在上方，相册放在下方并默认「按周」。左侧从早到晚列出每周日期和株数，每页最多 5 周，超过后使用上一页、下一页；右侧固定显示所选周的回顾和花园小图，窄窗口上下排列。每页最多 5 周，每组最多 12 座缩略图，也可通过日期直接定位到某周，包括空周。切换周时有轻柔过渡，并遵循系统减少动态效果设置。
- 最多保存 20 个种植方案，包含花种、目标时长、规则与惩罚设置，可载入、更新、删除，也能沿用上次种植设置。显示为「自定义内容 · 当前分类或规则 · 目标分钟」，分类改名后显示跟随更新，不重写已保存名称。在方案名中按 Enter 只保存方案，不播种。载入后仍由你确认播种，不复制上一朵花的名称和任务备注。
- 周回顾显示所选开花周的花朵数量、品种数、完成目标时长及品种分布，不包含当前未开花盆栽，也不把目标时长称为实际周专注时间。
- 种下时可填写最多 280 字符的任务记忆，之后可在当前盆栽或花朵详情中编辑。备注仅保存在本地，不放进开花通知，旧花不会自动补写历史。
- 36 级永久成就，合并在 16 张卡片中，包含 1～1000 株的九档累计开花、三档品种数量和八种植物各自的首次开花。小图列表可筛选，点击后在右侧非模态抽屉查看条件、进度和奖励，获得后删花也不会撤回。
- 默认「草木晴日」保留秋千、木牌和浇水壶；解锁后的「雨后小憩」「晚灯花园」「樱枝来信」各有三种原创摆设，并同步改变草坪、岛侧面、花圃、水池、围栏、路径与远景配色。全景与缩略图使用同一主题，花朵不加颜色滤镜；主题不改变生长规则。
- 默认主题秋千轻摆，其他主题增加叶尖水滴、暖光萤火或少量落樱，摆设使用简单固定阴影。蓝山雀、知更鸟、绿金翅雀及三色蝴蝶随机来访，池塘有微波和反光，来访间隔不变；缩略图保持静态。动效可关闭并遵循系统减少动态效果设置。关闭、离开花园页签或隐藏页面时，取消当前飞行并保留下次来访的等待时间，连续动效暂停。
- 当前盆栽和播种页在 540 CSS 像素及以上采用两列：活动盆栽左侧植物与进度，右侧约定、规则、备注和通知；播种左侧方案与花种，右侧新花设置。窄窗上下排列，原有紧凑盆栽模式保持不变，高清图鉴仍按需展开。
- 点击花朵后，右侧叠加显示非模态详情抽屉，不会滚到场景下方；仍可点其他花来切换详情。重命名、移除都在抽屉内完成，可点「关闭」、按 Esc 或点外部关闭；切换周、花园或页签会清除选中，轮询不会自动展开。
- 种植表单中的可展开图鉴展示高清盆栽插画；花园使用另外生成的地栽小花簇素材，不再把盆栽卡片缩小排列。
- 八种植物的图鉴都加入了来源、小故事及明确区分的文化花语或本园寓意，资料来自 Kew、RHS、高校与 Greenaway 公版花语书，可离线阅读；[完整资料出处](plant-guide-sources.md)随包提供。
- 直接选择 Hindsight 已有的分类或大类，无需重新填写里面的应用和网站；也保留手动程序、网站规则。任一规则匹配就生长，同一段时间只算一次。
- 当前盆栽支持「修改规则」，保留已有进度、目标时间和惩罚设置，不用重新种植。
- 默认累计模式，可以跨天继续；切换到其他程序只暂停，不枯萎、不扣进度。
- 可选中断惩罚：宽限期结束后，按当前进度的百分比或固定分钟数扣减，同一次连续离开只扣一次，最低为零。
- 花开后逐株归档留在花园里，可查看日期、重命名或删除；同一时间只养一盆，不会自动删除旧花。
- 支持紧凑盆栽界面，可选择开花时发送无声系统通知。通知只有一个控件，位于种植计划右栏；有活动盆栽时放入约定卡，不另设底部设置卡。

手动暂停、收到离开电脑事件、后台重启、未观察到的时间间隔都不惩罚。关闭插件页面后，只要 Hindsight 和插件后台仍在运行，就能继续累计。

## 安装与开始

需要 Hindsight **0.10.0 或更新版本**。0.15.0 是实验性个人插件的预发布版，并非官方插件。**目前基础功能已经可用，仍在开发和持续迭代，未经严格、全面测试，可能存在问题和风险。**

1. 从[发布页](https://github.com/Yoshino2000/hindsight-garden/releases)下载预发布的 `hindsight-garden-0.15.0.zip`，或按开发说明自行打包。
2. 打开 Hindsight 的「设置 → 插件」，选择从本地 ZIP 安装。
3. 确认七项权限和 64 MB 数据库存储额度后安装。
4. 打开「时光花园」，选择植物、填写名字和目标分钟数，再从下拉框选择已有分类或大类。

**升级前请先备份插件数据库。** 可关闭 Hindsight 后备份，或在运行时使用 SQLite 在线备份取得一致副本。直接安装新版 ZIP 更新同一个插件，不要先删除插件数据。0.15.0 仍使用 schema 2、七项 API 权限和 64 MB 额度。从 0.11.0 升级时沿用永久计数，一次核验并补授已满足的新成就，保留原四项获得日期；新补授项显示本次核验日期，不猜测历史日期。更早花园首次按现存收藏核验起点，旧版已删除的花无法恢复计数。从更早版本升级时，仍会包含 0.5.0 引入的 4 MB → 64 MB 额度变化；从 0.1.0 升级还会包含 0.2.0 新增的三项分类权限。

**不要直接降级，也不要同时运行新旧版本。** 0.11.0 会拒绝不认识的新成就标识；0.5.0～0.10.0 不能保留方案、成就和任务备注，数据库写入保护会阻止这类不兼容状态更新。旧页面或后台因此可能报错，应关闭旧版并重新打开最新版。确需退回旧版，应恢复升级前的一致备份；schema 编号相同不代表降级安全。

从 schema 1 版本升级时，会把成熟花原子迁移到 schema 2，按株保存到 SQLite 归档，保留当前盆栽、已有进度和设置；归档失败时整笔回滚，旧记录保留。0.5.0 之前的插件不能读取 schema 2，不应直接降级到这些版本；确需退回时，使用迁移前备份恢复。已经种下的盆栽仍可点「修改规则」换成分类，不会清空进度。

按周查看时，以**开花日期**归档，而非种下日期。每周从本地时间周一 00:00 开始，到下周一 00:00 之前结束。周列表包含本周、有花的历史周，以及已经选中的空周，日期直达可选择其他空周。相册打开时优先按周展示，但保留历史所选周和花园页码。回顾中的「完成目标时长」是本周开花花朵的目标之和：跨周生长的花全部计入开花周，不能据此还原每日使用或中断前累计时间。删除花会改变当前收藏的回顾，已获得成就则保留。

每座花园最多 25 株，当周超过 25 株时自动放入第 2 座、第 3 座花园。「全部」模式按种下日期和植物标识稳定排序。取消固定株数上限不等于无限磁盘容量：仍受 64 MB 数据库额度、宿主限制及可用磁盘空间约束。空间不足时会保留旧记录并提示，不会自动删花腾位置。

花园中的花只来自真实完成的盆栽，景物不会虚构花朵或累计时间。选择花朵后在右侧抽屉查看日期、目标时间并进行重命名或移除；切换「按周 / 全部」、周、花园或页签都会清除选中并关闭抽屉，后台轮询不会自动展开。展示偏好仍只保存在本机，与花园收藏数据、紧凑模式及环境动效偏好分开。暂停环境动效不会暂停植物生长。

切换页签时会清掉先前的成功提示和页面操作错误；仍在发生的后台运行错误继续显示，不会因翻页被隐藏。

0.15.0 的 170 项自动测试通过，并已用隔离数据检查五周分页、五档徽章与主题动效；本轮尚未把最终 ZIP 安装到真实 Hindsight 中验证，旧版检查不能代替本版实机验证。实际记录见[验证范围](verification.md)，行为与升级细节见[本版功能说明](features-0150.md)。

默认在独立普通窗口打开。窗口有标题栏和背景，也会被其他窗口遮挡；不能透明悬浮、始终置顶、鼠标穿透或在桌面行走。「紧凑模式」只简化插件界面，不改变系统窗口性质。在 Hindsight 的插件设置中可以选择主窗口或独立窗口。

## 规则和惩罚

生长目标为 1～1440 分钟。分类规则直接使用 Hindsight 的分类标识，大类规则包含该大类下的分类。分类重命名后规则仍有效；分类删除后不再匹配，可点「刷新分类」更新名称和选项。Hindsight 修改应用归类后，收到下一次前台事件时会按新的归类判断；插件不会另建一份应用名单，也不会修改 Hindsight 分类。

程序可以按完整名称或名称包含关系匹配，不区分大小写，并忽略结尾的 `.exe`。网站按域名及其子域名匹配：`example.com` 包含 `docs.example.com`，不包含 `notexample.com`。输入完整 URL 时只保留域名，不能按文章或路径区分。

惩罚默认关闭。启用后，宽限时间可设 0～300 秒：

- **百分比**扣当前已累计进度，不扣目标时长。已有 40 分钟，扣 10% 后剩 36 分钟。
- **固定分钟**从当前进度扣除，已有 40 分钟，扣 5 分钟后剩 35 分钟。
- 宽限期内回来就不扣；在多个不匹配程序间切换不会重置宽限，也不会反复扣。
- 手动暂停或离开电脑会取消待执行的惩罚；恢复使用不会因为这段休息再扣。

这里记录的是符合规则的**前台使用时间**，不能证明注意力或工作成果。后台标签页不计时，Hindsight 的采样和空闲设置会影响结果。重启后等待新的焦点事件；连续检查间隔超过 10 秒或系统时间倒退时，不补算、不惩罚，等待新事件。不能补算关闭 Hindsight 期间的使用，也不读取历史明细。操作页面时可能保守少算不足一轮检查的时间。

## 权限和数据

| 权限 | 用途 |
|---|---|
| `focus.changed` | 收到前台变化和用户离开事件 |
| `focus.app` | 按程序名称匹配 |
| `focus.title` | 获取网站域名；接口同时提供标题，插件会丢弃标题 |
| `focus.category` | 使用当前前台活动所属的分类和大类 |
| `categories.read` | 在下拉框列出 Hindsight 已有分类 |
| `super_categories.read` | 在下拉框列出 Hindsight 已有大类 |
| `notifications` | 可选的开花通知 |
| `storage_mb: 64` | 在插件自己的 SQLite 数据库中保存当前盆栽、设置和逐株成熟花归档 |

不申请历史统计、截图、任意文件读写或启动程序的能力。运行时不联网，不保存窗口标题或活动流水。规则、所选分类标识和名称、植物、可选任务备注、种植方案、成就进度以及最近观察到的程序/域名/分类保存在插件本地数据库；主题等展示偏好保存在本地存储。插件数据库不会由 Hindsight 跨设备同步。卸载时如果选择删除插件数据，花园也会被删除。

## 推荐花名与分级展示

点击「给它取个名字」旁的「推荐」，优先使用已选且仍可用的分类或大类，组合成「分类的花名」。没选分类时，从论文阅读、娱乐休息、游戏放松等十种任务中随机组合。多个候选尽量不连续重复，只有一个分类时名称相同；推荐后仍可编辑，切换花种不会自动覆盖手工名称。

相关成就仅合并展示，徽章分白、蓝、紫、金、彩五档颜色，详情保留全部原始条件和获得日期，不清零、不重算。1～1000 朵的九档累计数量共用「花开成园」；卡片默认白底，整组全部获得后才填淡黄。动效开关位于花园顶部，底部左侧切换花园。


## 有效生长与新成就

0.15.0 新增连续 5／15／25／45／60 分钟、累计 1／5／10／25／50 小时、分类多样性及三种配比条件。只统计升级后本插件实际获得的生长时间，不读取全部历史活动或回推旧花。分类比例分母包含未分类和其他；最多单列 24 个真实分类，其后新分类汇总为其他。卡片的“条件进度”不是实际分类百分比。

**成就 revision 3，旧版至 0.14.0 无法安全读写新状态。** 更新前关闭旧页面和后台；需要回退时恢复一致的升级前备份。schema 2、七项权限和 64 MB 不变。当前盆栽会具体说明为什么暂停；四主题的池塘都有波纹与荷叶微漂，樱瓣从顶部飘落后在草坪渐隐。
