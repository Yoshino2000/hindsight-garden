# 时光花园

简体中文 · [English](../../README.md)

使用电脑时，慢慢养出自己的花园。这是 [Hindsight](https://github.com/Tomotsugu-dev/Hindsight) 的第三方插件，包含可爱风格的 AI 原创植物素材，无需账号或联网。

## 能做什么

- 向日葵、绣球、郁金香、雏菊四种植物，各有种子、发芽、长叶、花苞、开花五个阶段。
- 绑定一个或多个前台程序、网站域名，任一规则匹配就生长。同一段时间只算一次。
- 默认累计模式，可以跨天继续；切换到其他程序只暂停，不枯萎、不扣进度。
- 可选中断惩罚：宽限期结束后，按当前进度的百分比或固定分钟数扣减，同一次连续离开只扣一次，最低为零。
- 花开后留在花园里，可查看日期、重命名或删除；同一时间只养一盆。
- 支持紧凑盆栽界面，可选择开花时发送无声系统通知。

手动暂停、收到离开电脑事件、后台重启、未观察到的时间间隔都不惩罚。关闭插件页面后，只要 Hindsight 和插件后台仍在运行，就能继续累计。

## 安装与开始

需要 Hindsight **0.10.0 或更新版本**。这是实验性的个人插件，未经全面测试，可能存在问题和风险，并非官方插件。

1. 使用随附的 `hindsight-garden-0.1.0.zip`，或按开发说明自行打包。这个初版本尚未公开发布或上架。
2. 打开 Hindsight 的「设置 → 插件」，选择从本地 ZIP 安装。
3. 确认四项权限和 4 MB 数据库存储额度后安装。
4. 打开「时光花园」，选择植物、填写名字、目标分钟数和匹配规则。

默认在独立普通窗口打开。窗口有标题栏和背景，也会被其他窗口遮挡；不能透明悬浮、始终置顶、鼠标穿透或在桌面行走。「紧凑模式」只简化插件界面，不改变系统窗口性质。在 Hindsight 的插件设置中可以选择主窗口或独立窗口。

## 规则和惩罚

生长目标为 1～1440 分钟。程序可以按完整名称或名称包含关系匹配，不区分大小写，并忽略结尾的 `.exe`。网站按域名及其子域名匹配：`example.com` 包含 `docs.example.com`，不包含 `notexample.com`。输入完整 URL 时只保留域名，不能按文章或路径区分。

惩罚默认关闭。启用后，宽限时间可设 0～300 秒：

- **百分比**扣当前已累计进度，不扣目标时长。已有 40 分钟，扣 10% 后剩 36 分钟。
- **固定分钟**从当前进度扣除，已有 40 分钟，扣 5 分钟后剩 35 分钟。
- 宽限期内回来就不扣；在多个不匹配程序间切换不会重置宽限，也不会反复扣。
- 手动暂停或离开电脑会取消待执行的惩罚；恢复使用不会因为这段休息再扣。

这里记录的是符合规则的**前台使用时间**，不能证明注意力或工作成果。后台标签页不计时，Hindsight 的采样和空闲设置会影响结果。重启后等待新的焦点事件；连续检查间隔超过 10 秒或系统时间倒退时，不补算、不惩罚，等待新事件。不能补算关闭 Hindsight 期间的使用，也不读取历史明细。操作页面时可能保守少算不足一轮检查的时间。

## 权限和数据

| 权限 | 用途 |
|---|---|
| `focus.changed` | 收到前台变化和用户离开事件 |
| `focus.app` | 按程序名称匹配 |
| `focus.title` | 获取网站域名；接口同时提供标题，插件会丢弃标题 |
| `notifications` | 可选的开花通知 |
| `storage_mb: 4` | 在插件自己的 SQLite 数据库中保存植物、设置和收藏 |

不申请历史统计、截图、任意文件读写或启动程序的能力。运行时不联网，不保存窗口标题或活动流水。规则、植物资料以及最近观察到的程序/域名保存在本地。插件数据库不会由 Hindsight 跨设备同步。卸载时如果选择删除插件数据，花园也会被删除。

## 开发、素材与验证
